# Design systems

Eén map per merk of stijl, gemaakt met `/design-systeem`:

```
design-systems/
  ACTIEF                 # één regel: de mapnaam van het systeem dat nu geldt
  <naam>/
    DESIGN.md            # het regelboek (vorm: .claude/skills/design-systeem/template.md)
    tokens.css           # alle waarden als :root-variabelen, licht en donker
    voorbeeld.html       # proefpagina om het systeem te zien
```

Nog leeg. Zeg in Claude Code bijvoorbeeld:

- "Maak een design system voor [bedrijf]" (vanaf nul)
- "I love this. Turn it into a design system." met een screenshot, deck of URL
- "Zoek drie Refero-stijlen die passen bij [wat je doet en voor wie]"
